# Changelog

Notable project changes are recorded here using a simple
Keep-a-Changelog structure. The package metadata is currently at development
version `0.1.0`; no formal release has been published.

## [Unreleased]

### Added

- Repository checks for Python linting and a required, unconditional test run.
- Dependency update automation for Python packages and GitHub Actions.
- Consistent editor settings and a private security-reporting guide.
- Playable REDLINE racing championship with three authored circuits, route
  planning, deterministic rivals, dynamic race events, and season standings.
- Twelve required algorithm families, the Algorithm Lab, all three assignment
  challenges, five reproducible studies, automated tests, and Windows CI.
- Bundled original artwork and sound, licensed Barlow fonts, technical report
  source, and submission packaging tools.

### Changed

- Set the package metadata to development version `0.1.0`.
- Improved generated-file exclusions and repository setup documentation.
