# Display typography

REDLINE uses Barlow Condensed Bold Italic for its wordmark and display titles,
Barlow Condensed SemiBold for compact controls, and Barlow Regular for body
text. The Barlow Project Authors created the fonts. These are unmodified TrueType files distributed under the
[SIL Open Font License 1.1](OFL.txt).

The files came from pinned revisions of the Google Fonts repository.
[Barlow Condensed](https://github.com/google/fonts/tree/60824dce48f7dd28fe7d65559f2da1f6e04e585b/ofl/barlowcondensed)
and [Barlow](https://github.com/google/fonts/tree/6cdf01867df0813c2390f90dff7dc66c87f14cf7/ofl/barlow).
